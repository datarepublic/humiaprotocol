# HUMIA Protocol v0.3 — Candidate Draft

Public HTML copy: `site/spec/v0.3/index.html`.

This draft is experimental. It is being prepared for external review and a possible provisional IANA Well-Known URI registration request. No IANA registration or AI-provider adoption is claimed.

Core candidate discovery URI: `/.well-known/humia.json`.
Optional discovery bridge: `Humia: https://example.org/.well-known/humia.json` in `robots.txt`.

The v0.3 draft explicitly separates resource **access** from intended **usage purpose**.
