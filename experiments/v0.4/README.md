# HUMIA v0.4 — Experimental

This directory contains an experimental design for HUMIA v0.4.

It is not deployed and is not the current public HUMIA version.

Current public version:
- HUMIA v0.3
- https://humiaprotocol.org/

v0.4 explores a simpler model:

- RFC 9309 / robots.txt for crawl behavior
- AIPREF for AI content-use preferences
- HTTP/auth for protected access
- HUMIA for the origin-level cooperation profile
- HUMIA-specific attribution and reciprocity only where useful

The purpose of this experiment is to avoid duplicating existing standards
and to test a practical cooperation profile on real websites.

Do not deploy this prototype as a stable HUMIA specification yet.
