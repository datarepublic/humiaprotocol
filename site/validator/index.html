HUMIA / Validator V0

Validate a HUMIA policy.

Enter a public website origin. The validator checks the canonical /.well-known/humia.json policy against HUMIA Protocol v0.3 and inspects the optional Humia: discovery record in /robots.txt.

Use the public HTTPS origin only — no path.

No account · no storage · fixed public HUMIA endpoints only

Experimental · v0.3 Draft

What is checked?

  • HTTPS policy retrieval
  • JSON syntax and media type
  • protocol: "HUMIA"
  • version: "0.3"
  • Canonical origin identity
  • Defined access and usage values
  • Attribution and reciprocity fields
  • Optional robots.txt discovery
No site checked yet.

The result will distinguish protocol errors from optional warnings. A missing Humia: robots.txt line does not make a HUMIA policy invalid.
